# B14-A6-Fit Log

FitLog is a responsive workout library and gym companion. Browse exercises,
add up to five lifts to today's plan, and save other workouts for later.

## Technologies

- Next.js App Router
- React and TypeScript
- Tailwind CSS and DaisyUI
- FitLog Workout API

## Features

- Responsive workout library with exercise details from the FitLog API
- Mobile-friendly navigation and workout detail pages
- Today's workout plan with a five-exercise limit and live totals
- Save workouts for later and view plan/saved counters in the navbar
- Sort today's plan and saved workouts by duration, calories, or rating
- Local storage keeps the plan and saved workouts after a reload
- Toast notifications for workout actions
- Custom 404 page for unknown routes and workout details
